# КТА · Тренажёр для подготовки к магистратуре (группа M094, ИТ)

Веб-приложение (PWA) для подготовки к комплексному тестированию.
Работает офлайн, ставится на телефон как приложение.

## Формат реального КТА (по данным testcenter.kz)

**130 заданий · 235 минут · максимум 150 баллов**

| Блок | Заданий | Баллов | Формат ответа |
|---|---|---|---|
| Иностранный язык (английский) | 50 | 50 | один правильный |
| Готовность к обучению | 30 | 30 | один правильный |
| Профиль 1 — алгоритмы | 30 | 30 | один правильный |
| Профиль 2 — базы данных | 20 | 40 | **один или несколько** (не более трёх) |

**Пороги:** всего не менее 75 баллов · английский не менее 25 · каждый другой предмет не менее 7.

## Возможности

- **312 вопросов** с пояснением к каждому
- **Теория по темам** — 15 конспектов с таблицами, формулами и разбором ловушек
- **Режим настоящего экзамена** — 130 вопросов в правильной пропорции, таймер на 235 минут,
  навигация по номерам вопросов, подсчёт баллов по блокам с проверкой порогов
- **Умное повторение** — ошибки возвращаются по интервалам (1, 3, 7, 16, 35 дней)
- **Статистика** — прогноз баллов на экзамене и список слабых тем
- **Перемешивание вариантов** — чтобы запоминать содержание, а не букву ответа
- Блок «Базы данных» — с множественным выбором, как на реальном КТА (максимум 3 ответа)
- Прогресс сохраняется на устройстве, тёмная/светлая тема автоматически

## Как открыть

### На компьютере
Открой `index.html` двойным кликом — работает без интернета.

### На телефоне (рекомендуется)
```bash
cd "kta-app"
python3 -m http.server 8000
```
Узнай IP компьютера: `ipconfig getifaddr en0` (Mac).
На телефоне открой `http://<IP>:8000` — например `http://192.168.0.181:8000`.
Затем меню браузера → «На экран Домой» / «Установить приложение».

**Чтобы открывалось откуда угодно:** загрузи папку `kta-app` на
[Netlify Drop](https://app.netlify.com/drop) или GitHub Pages.

## Как добавить свои вопросы

Вопросы лежат в `questions.js`:
```js
{
  id:'уникальный_id',
  subject:'readiness | english | algorithms | databases',
  topic:'Название темы',
  type:'single',              // 'multi' — несколько правильных ответов
  q:'Текст вопроса',
  passage:'текст для заданий на чтение',   // необязательно
  code:'блок кода',                        // необязательно
  options:[{k:'A',t:'вариант A'},{k:'B',t:'вариант B'}],
  correct:['A'],              // для multi: ['A','C','F'] — максимум 3
  explain:'Пояснение к правильному ответу'
}
```
Темы группируются в крупные разделы — соответствие задано в `TOPIC_GROUPS` внутри `index.html`.

## Как добавить теорию

Теория в `theory.js`, ключ — `'предмет|Название группы тем'`:
```js
'databases|SQL-запросы': `<h3>Заголовок</h3><p>текст…</p>`
```
Доступны `<h3> <h4> <p> <ul> <ol> <table> <code> <pre>` и блок-предупреждение
`<div class="warn-box">…</div>`.

## Файлы
- `index.html` — приложение (интерфейс + логика)
- `questions.js` — банк вопросов
- `theory.js` — конспекты по темам
- `manifest.json`, `sw.js`, `icon.svg` — PWA (офлайн + установка на телефон)
